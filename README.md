# 🚗 Car Selling Price Prediction

A Machine Learning application that predicts the selling price of a used car based on its features.

## Features

- Manufacturing Year
- Present/Showroom Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Previous Owners

## Machine Learning Model

Random Forest Regression

## Dataset

301 car records

- Training records: 240
- Testing records: 61

## Model Performance

R² Score: 0.9652

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit
